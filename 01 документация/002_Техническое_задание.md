# Техническое задание

## Название проекта

ON CHILL CRM

---

## Цель проекта

Разработать современную CRM-систему для управления всеми процессами компании ON CHILL.

CRM должна объединить:

- клиентов
- заказы
- производство
- склад
- логистику
- финансы
- задачи сотрудников
- аналитику
- документы

---

## Основные требования

Система должна быть:

- быстрой
- масштабируемой
- безопасной
- простой для пользователя
- модульной

Любой раздел должен добавляться без переписывания существующего кода.
