# Структура базы данных

## Название проекта

ON CHILL CRM

---

# Общая информация

База данных строится по модульному принципу.

Каждый модуль является независимым.

Все связи должны быть реализованы через внешние ключи.

Удаление данных не должно нарушать целостность системы.

---

# Основные таблицы

- password_hash

# Связи

clients → orders

orders → order_items

products → order_items

products → production

products → warehouse

orders → finance

users → clients

users → orders

users → tasks

---

# Основные требования

Все таблицы должны иметь:

- id
- created_at
- updated_at

По возможности использовать UUID.

Все связи должны быть индексированы.
