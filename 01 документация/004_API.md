# API ON CHILL CRM

## Назначение

Документ описывает все методы API CRM.

Стиль API:

- REST
- JSON
- HTTPS
- JWT авторизация

---

# Авторизация

## POST /api/auth/login

Описание:

Вход пользователя.

Тело запроса:

```json
{
  "email": "",
  "password": ""
}
```

Ответ:

```json
{
  "token": "",
  "user": {}
}
```

---

## POST /api/auth/logout

Выход пользователя.

---

## GET /api/auth/me

Получить информацию о текущем пользователе.

---

# Клиенты

## GET /api/clients

Получить список клиентов.

Поддержка:

- поиск
- фильтр
- пагинация
- сортировка

---

## GET /api/clients/{id}

Получить клиента.

---

## POST /api/clients

Создать клиента.

---

## PUT /api/clients/{id}

Редактировать клиента.

---

## DELETE /api/clients/{id}

Удалить клиента.
